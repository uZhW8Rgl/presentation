# Technology symbols for slides 2, 4 and 5

The general concepts use locally drawn symbols in `technology_icons.py`:
blockchain (connected blocks), encryption (padlock), zero knowledge (ZK seal),
TEE (chip with lock), remote attestation (checked certificate), decentralized
federated learning (peer mesh), and AI agent (robot).
These are illustrative symbols, not official technology or project logos.

`mcp.svg` is the original Model Context Protocol mark, retrieved on
8 September 2026 from the [official repository](https://github.com/modelcontextprotocol/docs/blob/573dc60c2e7aab2605b29d0bf27194aa7b02e4fb/favicon.svg).
Its geometry is reproduced as editable PowerPoint strokes, in black on slide 2
and white on slide 4's dark background.
The mark identifies MCP; it does not imply endorsement.

All symbols remain editable native PowerPoint elements. The original
technology descriptions are retained in the slide's speaker notes.

Slide 4 reuses the eight symbols in two columns and four rows. The color
families remain green, blue and orange, with lighter tones for contrast on
the existing dark panel. The panel heading is retained; its previous rows,
numbered circles, arrows and closing caption are removed.
Ten light-gray arrows connect neighboring symbols horizontally and vertically.

Slide 5 uses a horizontal sequence between the red gap statement and the
compact RQ cards: Security (padlock), TEE, Remote Attestation, Blockchain,
DFL, MCP and Agent. The first four arrows point right; the last two point
left, from Agent to MCP and from MCP to DFL.
