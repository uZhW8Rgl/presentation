# Blockchain and IPFS inside DFL

Three editable proposals in `VITA-FL_Lifecycle_Infrastructure_Inside_DFL.pptx`:

- **I1:** stacked infrastructure in the DFL circle, followed by a separate published-model symbol.
- **I2:** infrastructure tiles side by side, with one compact published-model path to inference.
- **I3:** internal infrastructure with two explicit outputs: model reference and model files.

The ring represents repeated local training, aggregation, and global-model redistribution.
Blockchain and IPFS are shared components, not extra sequential stages. Their placement
inside the ring groups their DFL functions; it does not define a common trust boundary.
The receiver can access both for inference. Speaker notes explain the single-path abstraction
and the explicit retrieval paths. The transparency log remains distinct from the blockchain.

Previous proposals, original A, and the main presentation are preserved.
